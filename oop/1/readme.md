# Dog Class Sample (Python OOP)

Pythonのクラス（オブジェクト指向プログラミング）の基本である **プロパティ・メソッド・カプセル化（`@property`）** を学ぶためのシンプルなサンプルプロジェクトです。

## ファイル構成

```text
.
├── dog.py       # Dogクラスの定義と実行サンプル
├── main.py      # Dogクラスを読み込んで動かすメインスクリプト
└── README.md
```

## 主な機能（`Dog` クラス）

* **プロパティとカプセル化**
  * `name`: 犬の名前（初期値 `"ポチ"` の公開プロパティ）
  * `genki`: 元気度（初期値 `3`）。内部では `self.__genki` として保持し、`@property` を使って**読み取り専用**にしているため、外部から直接書き換えると `AttributeError` になります。
* **メソッド**
  * `bark()`: 鳴き声（`"ワン"`）を返します。

## 動作環境

* Python 3.x（標準ライブラリのみ使用しているため、追加のインストールは不要です）

## 使い方

### 1. メインスクリプトの実行

```bash
python3 main.py
```

### 2. `dog.py` 単体の実行

`dog.py` 内の `if __name__ == "__main__":` ブロックにより、単体でも動作確認ができます。

```bash
python3 dog.py
```

**実行結果:**

```text
ポチ
ワン
```
