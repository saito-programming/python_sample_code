# Dog Class Sample (Python OOP)

Pythonのクラス（オブジェクト指向プログラミング）の基本である **プロパティ・メソッド・カプセル化（`@property`）・ユニットテスト** を学ぶためのシンプルなサンプルプロジェクトです。

## ファイル構成

```text
.
├── dog.py       # Dogクラスの定義と実行サンプル
├── main.py
├── test_dog.py  # unittestを使ったテストコード
└── README.md
```

## 主な機能（`Dog` クラス）

* **プロパティとカプセル化**
  * `name`: 犬の名前（公開プロパティ）
  * `genki`: 元気度（初期値 `3`）。内部では `self.__genki` として保持し、`@property` を使って**読み取り専用**にしているため、外部から直接書き換えると `AttributeError` になります。
* **メソッド**
  * `bark()`: 元気度が1以上あれば1消費して鳴き声を返し、`0` の場合は疲れたメッセージを返します。
  * `eat()`: 餌を食べて元気度を1回復させます。

## 動作環境

* Python 3.x（標準ライブラリのみ使用しているため、追加のインストールは不要です）

## 使い方

### 1. サンプルの実行

```bash
python3 dog.py
```

**実行結果の例:**

```text
ポチは疲れるまで吠え続けます
ポチ:[ワン]
ポチ:[ワン]
ポチ:[ワン]
ポチは疲れたようです
ポチは餌を食べて少し元気になったみたいです
ポチ:[ワン]
```

### 2. ユニットテストの実行

標準ライブラリの `unittest` を使用して、`Dog` クラスの動作や読み取り専用プロパティの挙動をテストできます。

```bash
python3 -m unittest test_dog.py
```
